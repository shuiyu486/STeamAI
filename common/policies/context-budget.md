# Context budget and progressive disclosure

目标：让主会话只保留决策所需信息，避免把长历史、大文件和工具原始输出灌入上下文。

## 默认预算

| 内容 | 建议预算 |
|---|---:|
| 常驻项目说明 | 8KB |
| 接手文档 | 12KB |
| 单个专项 reference | 16KB |
| 归档、大 CSV、trace、dump | 不主动读入 |

## 读取原则

- 先读路由文档，再按任务读取专项文档。
- 大文件优先用脚本、CSV 过滤、摘要或行范围读取。
- 工具输出只保留路径、摘要、关键定位和必要错误。
- 历史归档只在需要追溯原因时读取片段。

## 渐进式披露

1. 常驻层只放授权、边界、当前入口和路由。
2. 接手层放当前任务状态和下一步。
3. 专项层按任务读取。
4. 机器数据留在 CSV/JSON/log 中，按需过滤。

## 与 pack overlay 的关系

本文件只定义通用预算。具体哪些目录、CSV、trace 或 artifact 不能整读，由 pack overlay 说明。
