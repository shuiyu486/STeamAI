# Tactical subagent

短命 tactical subagent 用于搜索、只读分析、反驳、窄复核或隔离的小修，不是 durable member，也不能自行招募成员。

## 使用条件

- 输入范围、输出格式和停止条件明确；
- 任务可独立验证，不要求长期持有身份或上下文；
- 并行任务不会修改同一文件或外部状态。

不要为“更并行”增加 agent。普通分片保持 2–4 个；高风险结论优先使用一名 owner 加一名独立 verifier。

## 边界

- 默认只读；需要写入时使用隔离工作区或无冲突边界，由所属成员审查 diff。
- 不执行 heavy action，不改变 case 授权，不成为团队消息中转站。
- 返回结论、最多 3 条关键证据、主要风险和下一步；不回传长日志或大段文件。
- 卡住时返回具体缺口，不扩大范围或无界等待。

结果由启动它的成员负责验证、整合和持久化。只有需要团队复核的 evidence、finding 或 review 才进入 case 文件。
