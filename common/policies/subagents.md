# Tactical subagent

短命 tactical subagent 用于搜索、只读分析、反驳、窄复核或隔离的小修，不是 durable member。鼓励各角色把杂活、重复整理、大文件筛选和可封装的短链路任务交给它，避免主会话因原始输出与多轮压缩积累噪声；主会话负责方向、核验和整合。

## 使用条件

- 输入范围、输出格式和停止条件明确；
- 任务可独立验证，不要求长期持有身份或上下文；
- 并行任务不会修改同一文件或外部状态。

每批最多 5 个且不嵌套；子 agent 不得再启动子 agent 或招募正式成员。简单任务直接做，不为“更并行”凑数量；高风险结论优先使用一名 owner 加一名独立 verifier。默认显式选 `sonnet`，需要复杂推理或独立反驳时按任务选 `opus`，不默认继承启动它的高档模型。档位沿用用户的 `ANTHROPIC_DEFAULT_*_MODEL` 映射，不改用户全局配置。

## 边界

- 默认只读；需要写入时使用隔离工作区或无冲突边界，由所属成员审查 diff。
- 不执行 heavy action，不改变 case 授权，不成为团队消息中转站。
- 返回结论、最多 3 条关键证据、主要风险和下一步；不回传长日志或大段文件。
- 卡住时返回具体缺口，不扩大范围或无界等待。

结果由启动它的成员负责验证、整合和持久化。只有需要团队复核的 evidence、finding 或 review 才进入 case 文件。
