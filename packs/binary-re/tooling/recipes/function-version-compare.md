# Function version compare

两个版本目标的功能级比较：交付"改变 / 未观察到改变 / 不可比较"三类判定，不把文本 diff 当语义等价证明。

## 输入

- 同一功能的两个授权版本（case-local artifact，登记 hash/bytes）。
- 每版一条有限功能链：入口 → 关键调用 → 数据变换/分支 → 最终效果（见 `bounded-behavior-chain.md`）。

## 步骤

1. 分别建立两版的功能链观察，关键边各自定位到真实观察（地址/指令/反编译行），不共享未验证假设。
2. 以功能链为对齐单位比较：哪个环节的输入/输出/选择分支发生变化；符号或地址漂移单独记录，不作为语义变化证据。
3. 证据分类：
   - **改变**：同一入口输入下观测到不同数据变换或最终效果，且能定位到具体分支/表项/条件。
   - **未观察到改变**：对齐后的环节观测一致（注明比较范围，不说"完全相同"）。
   - **不可比较**：一版缺符号/缺观察/分析深度不对称时如实标注，不强行 diff。
4. 版本间共享函数按调用链核对，不只比函数名；无符号版的候选对齐要有指令/结构证据。
5. 每个判定引用两版各自的 E；unknown 项（如无法确认的实现来源）保持 unknown。

## 输出与边界

- F 版本差异结论 + 两版 E 引用 + 不可比较清单。
- 至少一项"静态预测 → 运行时观测"对照（见 `runtime-observation.md`）；不一致时收窄静态结论。
- 大范围全文 diff、批量反编译导出不作为默认步骤。
