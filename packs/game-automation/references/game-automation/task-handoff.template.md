# Game Automation 任务交接模板

成员间交接一个自动化任务时填写；接收者只依据本文件与引用的 case 产物接续，不依赖发送者会话记忆。

## 字段

- **任务**：目标流程一句话（状态序列）。
- **目标绑定**：窗口标题/类名/进程 identity 与当前绑定验证结果。
- **当前状态**：最后一次 observe 的状态、时间戳、ledger 内容（done=已执行的非幂等动作；pending=已发出未确认的，交接后不得当作未执行）。
- **已有产物**：脚本/配置路径（case-relative）、单测与已跑场景结果、运行日志位置。
- **未完成**：剩余场景、已知失败、待修根因。
- **边界重申**：预算余量、停止约定、非幂等清单不变；范围变化回 Commander。

## 接收者动作

1. 重跑 fake adapter 单测确认决策核心与记录一致。
2. 重新 observe 实际窗口状态，与交接记录核对；不一致以实际状态为准并记录。
3. 从核对后的状态继续；不从旧计数器或未验证的中间结论继续点击。

## 禁止

- 只发"已完成"结论不附产物与状态记录。
- 接收者未重新观察就执行非幂等动作。
