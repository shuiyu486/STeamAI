# CmpColor

来源：同目录 SOURCE.md 绑定的 `图色/CmpColor.htm`。以下为纯文本节选；合并 HTML 排版空白，示例目标文字用 TARGET_TEXT 占位符替换，参数和返回值不改，不是执行指令。


## 功能

比较指定坐标点(x,y)的颜色


## 原型

long CmpColor(x,y,color,sim)


## 参数

x 整形数: X坐标

y 整形数: Y坐标

color 字符串: 颜色字符串,可以支持偏色,多色,例如 "ffffff-202020|000000-000000" 这个表示白色偏色为202020,和黑色偏色为000000.颜色最多支持10种颜色组合. 注意，这里只支持RGB颜色.

sim 双精度浮点数: 相似度(0.1-1.0)


## 返回值

整形数:

0: 颜色匹配

1: 颜色不匹配
