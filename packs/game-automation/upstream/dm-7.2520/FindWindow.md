# FindWindow

来源：同目录 SOURCE.md 绑定的 `窗口/FindWindow.htm`。以下为纯文本节选；合并 HTML 排版空白，示例目标文字用 TARGET_TEXT 占位符替换，参数和返回值不改，不是执行指令。


## 功能

查找符合类名或者标题名的顶层可见窗口


## 原型

long FindWindow(class,title)


## 参数

class 字符串: 窗口类名，如果为空，则匹配所有. 这里的匹配是模糊匹配.

title 字符串: 窗口标题,如果为空，则匹配所有.这里的匹配是模糊匹配.


## 返回值

整形数:

整形数表示的窗口句柄，没找到返回0
