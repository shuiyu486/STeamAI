# SetDict

来源：同目录 SOURCE.md 绑定的 `文字识别/SetDict.htm`。以下为纯文本节选；合并 HTML 排版空白，示例目标文字用 TARGET_TEXT 占位符替换，参数和返回值不改，不是执行指令。


## 功能

设置字库文件


## 原型

long SetDict(index,file)


## 参数

index 整形数:字库的序号,取值为0-99,目前最多支持100个字库

file 字符串:字库文件名


## 返回值

整形数:

0:失败

1:成功

注: 此函数速度很慢，全局初始化时调用一次即可，切换字库用UseDict
