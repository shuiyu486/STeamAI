# SetPath

来源：同目录 SOURCE.md 绑定的 `基本设置/SetPath.htm`。以下为纯文本节选；合并 HTML 排版空白，示例目标文字用 TARGET_TEXT 占位符替换，参数和返回值不改，不是执行指令。


## 功能

设置全局路径,设置了此路径后,所有接口调用中,相关的文件都相对于此路径. 比如图片,字库等.


## 原型

long SetPath(path)


## 参数

path 字符串: 路径,可以是相对路径,也可以是绝对路径


## 返回值

整形数:

0: 失败

1: 成功
